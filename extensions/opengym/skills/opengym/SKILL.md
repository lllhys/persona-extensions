# openGym（opengym 工具）

数据来自用户自建的 openGym 服务器，用的是用户在 openGym 设置里生成的 API 令牌。重量都是用户 openGym 里设的单位（kg 或 lb），工具的回答里写着，回答时照用，不要换算成别的单位，除非用户要求。

## 读

1. **概况先用 `opengym_summary`**：本周和上周的次数、训练量、时长，下一次计划练什么，最近体重，最近 12 周每周的训练量。
2. **训练记录用 `opengym_workouts`**：`{"limit": 10}`，或者 `{"from": "2026-10-01", "to": "2026-10-31"}`。要看某次训练每组的重量和次数，给 `workout_id`（列表里的 id）。
3. **计划用 `opengym_plan`**：未来 7 天每天练什么、为什么（每周计划、当天单独安排、改成休息、教练周），教练周的进度，以及每个训练计划的动作和计划 id。
4. **体重用 `opengym_bodyweight`**：`{"days": 90}`。
5. **动作编号用 `opengym_exercises`**：`{"query": "卧推"}`。记训练、建计划前，名字不确定就先查，不要猜编号。

训练量是热身以外每组「重量 × 次数」的和，计时和有氧的组不算。PR 是 App 标的破纪录。数字只来自工具的回答；没有记录就说没有，不要估。

## 写（每次都要用户在手机上确认）

- `opengym_log_workout`：记一次已经练完的训练。`exercises` 里每个动作给 `exercise`（编号或准确的名字）和 `sets`，每组给 `reps` + `weight`，或 `seconds`，或 `minutes`；热身组加 `"warmup": true`。动作库里没有的，用户同意后加 `"create_custom": true` 新建自定义动作。App 不会给这样记的训练补 PR 标记。
- `opengym_create_routine`：建一个训练计划（给用户建议计划时用），每个动作给 `sets` 和 `reps`（或 `seconds`），可加 `weight`、`rest_seconds`；给 `date` 就同时排到那天。
- `opengym_schedule_day`：改某一天：`routine_id`（练这个计划）、`"rest": true`（休息）或 `"clear": true`（回到每周计划）。

写之前先把要写的内容用一两句话告诉用户；用户在手机上拒绝了就不要换个说法再试。令牌只有「查看」权限时写会失败，告诉用户在 openGym 的「设置 › 集成 › API 令牌」里给训练或计划开「应用」。

## 说明

- 「教练周」是 openGym 里按顺序练、不固定哪天的一组训练；下一项是没做完的第一个，用户也可以把某一项排到某天。
- 正在进行中的训练、照片和 openGym 自带 AI 教练的对话，令牌读不到。
- 用户的令牌和服务器地址只在扩展设置里填，不要让用户把令牌发在对话里。
